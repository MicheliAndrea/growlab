# GrowLab Web

Next.js App Router frontend for the GrowLab operational dashboard.

Pages:

- `/dashboard`
- `/plants`
- `/plants/[id]`
- `/zones`
- `/zones/[id]`
- `/devices`
- `/devices/[id]`
- `/lighting`
- `/ai-analysis`
- `/wiki`
- `/firmware`
- `/settings`
- `/system`

Run:

```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE_URL` to the API URL, for example `http://localhost:8080`.
