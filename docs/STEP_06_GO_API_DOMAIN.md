# STEP 06 — Go API Domain

## Obiettivo

Implementare moduli API principali.

## Moduli

- Zones
- Plants
- Plant Timeline
- Plant Wiki
- Devices

## Regole

- Handler sottili.
- Services per logica.
- Repositories per DB.
- OpenAPI rispettato.
- Nessuna auth.
- Nessuna AI tecnica.
- Nessun comando irrigazione attivo.
