# STEP 00 — Project Overview

GrowLab è una piattaforma locale per home lab dedicata a gestione piante, zone, sensori IoT, controllo luci, storico dati, firmware ESP32 e predisposizione futura per AI e irrigazione.

## Architettura logica

```text
Browser
  |
  v
Next.js Web App
  |
  | REST client generated by Orval
  v
Go Gin API
  |------ PostgreSQL/TimescaleDB su db-host
  |------ Redis
  |------ Image/Firmware Docker volumes
  |------ Shelly Dimmer 2 HTTP local API
  |
  v
Go Worker
  |
  v
EMQX MQTT
  |
  v
ESP32 devices

monitoring-host:
Grafana + Prometheus + Loki + Alloy
(repo homelab monitoring separata)
```

## Vincoli

- Non implementare AI nella prima fase.
- Non implementare auth.
- Non attivare irrigazione.
- Non usare GORM.
- Non usare tRPC o GraphQL.
- Non containerizzare PostgreSQL principale.
- Non salvare immagini nel DB.
- Non monitorare direttamente le VM nel primo setup monitoring.
