# GrowLab — Feature Roadmap Add-on

Questo pacchetto contiene documentazione aggiuntiva da integrare nel progetto GrowLab Hybrid Edition.

## Quando applicarlo

Applicare dopo il completamento di:

```text
STEP_03_DATABASE_TIMESCALE
```

e prima di procedere con:

```text
STEP_04_OPENAPI_CONTRACT
```

## Regola importante

Questi documenti sono solo roadmap/progettazione.

Non devono causare:

- modifiche allo schema database già creato;
- nuove migrazioni;
- implementazione codice;
- attivazione AI;
- attivazione irrigazione;
- introduzione auth;
- modifica dello stack principale.
